# Security policy

Staffless is meant to run locally on `127.0.0.1` and has no authentication. Please don't expose it to the internet.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Email **admin@illegal.tr** with:

- what you found and how to reproduce it
- the version or commit you tested
- any ideas for a fix

You'll get a reply as soon as possible, and credit in the release notes if you'd like.
